# v2 style packs (plan M2 + QW5)

Branch `feat/v2-style`. Implements the style-pack half of the redesign plan
(`~/.blackhole/DeckSmith/2026-10-07/redesign/plan/2026-10-07-decksmith-redesign-design.md`, M2).
Everything is behind `--design v2` or an explicit `--theme <pack>`. With `design: classic`
(the default) the emitted bytes are v0.8.0's: the full suite, including the sha256 golden in
`test/wiring.test.ts`, passes unchanged.

## What a pack is

A pack is a `DeckTheme` in `src/emit/themes/packs.ts`: palette, plus a font stack that names a
**type spec**, plus a **skin**.

| piece | where | what it may change |
|---|---|---|
| palette | `DeckTheme` fields | colours; held to WCAG by `test/themes.test.ts` |
| type spec | `src/emit/type.ts` `TYPES` | body face, display face, eyebrow and headline size/weight/tracking/leading/case/gap, title-slide bounds. All geometry, all charged by `chromeHeight` |
| skin | `DeckTheme.skin` | paint only: colour, radius, shadow, decoration, body `background-image`, absolutely positioned pseudo-elements. Enforced per pack in `test/style-packs.test.ts` |

Six packs: `signal`, `blueprint`, `atlas` (dark) and `folio`, `chalk`, `journal` (light).

## Interfaces other tracks touch

- **`Face` (src/emit/svg.ts)** is now `Script | PackFace`. `Script` is the old
  `"latin" | "cjk" | "hangul"`; a classic stack still yields exactly that string.
  `PackFace = { script, glyphs: LatinFace, type: TypeSpec }`. Emitters pass it through
  unchanged and need to know nothing about it. Helpers: `scriptOf`, `typeOf(face)`
  (returns `CLASSIC_TYPE` for a bare script), and `displayFace(face)` (the same face measured
  in the pack's display glyphs).
- **`faceOf(fontStack)`** identifies the type spec by exact match of the stack, after stripping
  a leading `"Noto Sans (KR|JP|SC|TC)", `. Every spec's stack is unique, as a test requires.
- **`Theme.displayStack?`** (kit.ts) is the chrome's CSS stack. `deckLook` puts the CJK family
  in front of it, as it does for `fontStack`.
- **title.ts.** `chromeHeight`, `chrome`, `chromeCss` and the `title` emitter read sizes from
  `typeOf(face)` and measure in `displayFace(face)`. The exported `EYEBROW_*` and `HEADLINE_*`
  constants are still classic's, and a test pins `CLASSIC_TYPE` to them.
  **Merge note for feat/v2-fit:** the plan's `ScaleSpec` (`ctx.scale`) and this `TypeSpec` both
  describe the chrome's scale. When they merge, one should own it. The simplest route is for
  `ScaleSpec` to be derived from `typeOf(faceOf(theme.fontStack))`, so packs keep driving it.
  Three emitters call `chrome()` without a face (`stack.ts:526`, `equation-walk`,
  `equation-morph`). That only affects `unwidow`'s NBSP choice, never a height.
- **Skin selectors** are `.scene .eyebrow`, `.headline`, `.figwrap`, `.af-plate`, `.panel` and
  `.sub`. **Merge note for feat/v2-layout:** a renamed class drops its pack finish silently, so
  extend the skins when you add a figure frame.
- **Prefs** (`src/types.ts`): `design: "classic" | "v2"` (default `classic`) and `packSeed?`. CLI:
  `--design`, `--pack-seed` on plan/build/pack (`lookFlags`) and on narrate. Other v2 tracks
  should read the same `prefs.design` rather than add a second flag.
- **`chooseLook` / `rankPacks` (src/emit/themes/pick.ts).** Picking is deterministic:
  rendezvous hashing over `fnv1a(seed + pack)`, weighted 1 + affinity × archetype-family mix.
  `build` passes `accepts`, which rejects a pack whose staging changes the stop count recorded
  in the narration on disk (through `planCut`'s `assertNarrationStaging`), so a narrated rebuild
  never breaks. `narrate --design v2` stages in the same pick.
- **Fonts.** `refreshFont(..., theme?)` vendors the pack's faces from `@fontsource-variable/*`
  for every deck that wears the pack, CJK included, because hyperframes lint refuses a named
  family with no `@font-face`. Pack faces are declared with Inter's vertical metrics
  (`ascent/descent/line-gap-override`). Without that, Source Serif's taller boxes failed
  `svg_text_overprint` and `text_box_overflow` on a real deck. `vendorFace` is exported.
- **Width tables.** `src/emit/faces.ts` is generated by
  `node scripts/measure-faces.mjs --write [extra storyboard.json ...]`. Over 63,648 corpus runs
  (demo plus 20 HypePaper en storyboards, every weight) the tables under-predicted 0 runs. Mean
  over-prediction was 1.034 for Source Serif 4, 1.025 for Space Grotesk and 1.048 for IBM Plex
  Sans. Inter measured the same way came out at 1.058, so all three new faces sit inside Inter's
  baseline.

## Measured

- Pack spread with `rankPacks` over the 176 distinct HypePaper storyboards on disk (Oct 4-7):
  all 6 packs are used. The busiest pack takes 20.5% when seeded by source id and 25.0% when
  seeded by paper id. The first 20 decks take 30% and 25%. The target was at most 40%, with at
  least 3 packs in use.
- Gates on 4 real narrated decks (en, ko, ja, zh-Hans) under `--design v2`: see the commit
  messages. Frames were reviewed by eye.

## HypePaper (not edited, note only)

`backend/scripts/decksmith_deck_batch.py:1184` passes `--theme ink` to `plan`. Under v2 that is
harmless, because a default-valued theme counts as unstated and a storyboard's `ink` counts as
"nobody said". For clarity it should still be dropped. To switch HypePaper over:

1. Add `--design v2 --pack-seed <paper_id>` to both `narrate` and `build`, so a paper's languages
   share a pack and narration is staged in the pack it will be built in.
2. Leave `--theme` off both.

Rollback is `--design classic`.

## Not done here

- CJK decks keep Noto for every glyph, so their packs change palette, scale, eyebrow, framing
  and surface, but not glyph shapes. A serif CJK face (Noto Serif KR/JP/SC) would need its own
  width measurement and a different subset fetch.
- `pack` still records `storyboard.theme`, not the picked pack. A `talk.deck` rebuilt under v2
  re-picks deterministically, so this is only a reporting gap.
- `experiments/sweep` receipt must be re-run (`npm run sweep`) on the merged tree. Its
  fingerprint includes `package.json` dependencies, which this branch changes.
